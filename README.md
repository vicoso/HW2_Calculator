# HW2: Calculator
script calculator.py takes a mathematical expression asinput (via input()) and prints the result of its evaluation.

The program supports four basic arithmetic operations:

addition (+)

subtraction (-)

multiplication (*)

division (/)

An expression consists of two numbers (int or float) and one operator between them, separated by spaces.

Example:

```{r}
Input:  5 - 3
Output: 2.0
```
